FAQ

This page collects the questions that come up most often in use, answered as "which page to read first". Every one links to the page with the full story.

Check one thing before you file a bug

Plenty of "nothing happens" isn't a fault: it may be an Approval dialog waiting for your click, or this run queueing up (queued tasks are visible in the task centre in the right column and above the input). Glance at the screen for anything pending before deciding it's really stuck.

#The model can't connect, or the API Key is reported invalid

First go to "Settings → Model configuration" and check that this model has its API Key filled in. When you can't tell whether it's the key or the network, run the shortest request from "Settings → API test"; it goes down the same path as a real Chat and reports the result. For a custom endpoint, check that the Base URL and the request mode match (OpenAI-compatible / Anthropic / curl direct). For a local model, check that Ollama or LM Studio is running. See Models and API Keys.

#Why does the model not call Tools and only say what it would do?

First check whether "Settings → Auto-advance" has been turned off — it exists precisely to nudge the model into making the Tool call when it only makes a statement. Then check whether Continue Autopilot is on: it keeps a run going at the last moment when rounds run out. Also look for an Approval dialog waiting for "Approve" — without approval the model won't go on. The full mechanism is in Agent Autopilot and Target Mode.

#A terminal command got blocked

When a hard-coded risky rule matches (deleting files, privilege escalation, shutdown or restart, force push and the like) a dialog pops up for you to confirm, and before you approve you can read a one-line note on the command's purpose generated by the model. Catastrophic commands are forbidden unconditionally in every mode — that's by design. If the same kind of command keeps asking, switch this Chat or the default level to Auto Approval, which only stops risky ones. See Settings and security approvals.

#Chinese characters or emoji come out garbled

Reading and editing files recognises UTF-8, UTF-8 BOM, GB18030, GBK, UTF-16 and other common encodings automatically, so Chinese, emoji and full-width punctuation are kept exactly as they are; when an old encoding can't express new characters, the Tool upgrades the write encoding safely instead of dropping characters. Terminal output gets encoding-safe handling for native commands, and Windows no longer pops a black window full of mojibake. If you still hit garbling: first check the file hasn't been rewritten by an outside program in another encoding, then read it once more with the file reading Tool; if needed, save the content again as UTF-8.

#LAN or phone can't connect to SLATE

Check four things in order: are the phone and the computer on the same Wi-Fi; is the computer's firewall blocking the port (allow it the first time); is the address the one shown in Settings (it must carry the auth code); has the router turned on a guest network or AP isolation. If Settings says "remote service not started", restart the app. See Mobile remote control and LAN access.

#There's too much data — how do I clean it up?

Go to "Settings → Data backup → Storage" and look at the total and the breakdown first. After deleting a batch of sessions you can click "Compress" to actually get the space back; to start over completely, "Clear chats" deletes only sessions and messages and leaves long-term memory and preferences alone. When the built-in browser cache grows, click "Clear cache". Export a Backup first. See Data, backups and storage.

#How do I save Tokens, or turn off AI features I don't use?

Go to "Settings → AI assistance": it lists the 15 Token-consuming features outside Chat, each switchable on its own, and once off not a single request goes out for it. If you only Chat and run Tools day to day, compression Summary, memory distillation, conversation insight, automatic chat titles, prompt polish, image and video generation can all be off first. A tally above the list shows how many are already off. See Settings and security approvals.

#Too many sessions, and I can't bring myself to delete them

Every row in the "Tasks" column has "Archive" among its actions: press it and the session leaves the Tasks column without a single message touched — archive isn't delete. The one generating can't be archived; stop it first. To get it back, go to "Settings → Archived chats" and "Restore" it one by one and it reappears in the Tasks column; the "Delete" there is the one that wipes the messages too, with no way back. See Data, backups and storage.

#Some Tools are missing from the tool list

First look at the matching switches under "Settings → AI assistance": with sub-agents, image generation and video generation off, the Tools disappear from the tool catalogue outright, so the model can't see them and won't call them. Image and video generation also need a model and API Key set in the "Image generation / Video generation" blocks; without them they're unavailable too. If an external MCP Server is attached, its Tools are temporarily gone while the connection is down. See Built-in tools and Skills.

#A custom playbook won't pass validation

Playbooks use a minimal format: 2-space indent, block arrays, literal block scalars. Tab indentation, anchors, multiple documents and the like are all rejected, and the error states "line N: reason", so fixing along that line number gets you through. It won't save until validation passes; the editor validates as you write. Full fields and syntax are in Actions playbooks.

#How do I stop a debate half way?

The team panel has a stop button; one click interrupts the remaining speakers, and what has already been said is kept in full — no results lost. The run also goes into team history marked "aborted", and you can open it and keep reading — a run with no conclusion never gets one invented for it. After stopping you can keep asking, or open a new run with another set of roles. See AI Team and Workflows.

#Does switching Project interrupt a Chat that's running?

By default, no. The one you left keeps generating in the background, and its progress and outcome land in the task centre in the right column; within one Project runs are serial by default, across Projects they can be parallel, and how many run at once is set under "Settings → Multi-tasking and Projects". If you'd rather have the old "switching interrupts" behaviour back, turn the switch in that block off. See Projects, workspaces and per-project configuration.

#How do I set an access password for mobile?

SLATE's LAN access isn't protected by "setting a password" but by the auth code carried in the address: only a device coming in through the address shown in Settings or its QR code gets access, and access without the auth code is stopped automatically. So the way to protect it is this — don't send the address with its auth code, or the QR code, to anyone; sending it out is handing over the key. When you don't need remote control, close SLATE on the computer and the address stops working. See Mobile remote control and LAN access.

#How do I change the interface language?

The interface language is chosen at install (Simplified Chinese or English), and there's no in-app switch while it runs, so changing it means running the installer again and picking the other language. Switching language only affects interface copy; model output and your input are never translated. For details see Settings and security approvals.

#How do I migrate data to a new computer or after a reinstall?

Three steps: on the old machine, "Settings → Data backup → Download Backup" to get a JSON; on the new machine, "Settings → Data backup", click "Import Backup" and pick it; confirm and the page reloads itself. Import merges by ID, so existing data is skipped, but local preferences are replaced by the copy in the Backup. Knowledge base documents, playbooks, Expert Packs and custom Skills aren't in that JSON — bring the local data directory across as well. See Data, backups and storage.

#How do I use a generated prompt in Claude Code, Codex or Cursor?

Prompt Factory produces a plain-text Prompt you can hand over: copy the whole thing and paste it into the external Coding Agent's dialog or Project instructions file, with no format changes needed. To make it fit a particular Tool's habits, write the delivery requirements and constraints clearly in the factory before generating. See Prompt Factory.

#What is it good for, and what isn't it good for?

It's good for turning an idea into a structured plan, for driving local Tools to get work done, for writing a repeated process down as a playbook you can reuse, and for producing a high-quality Prompt for an external Coding Agent to execute. It isn't good as a pure cloud assistant, for multi-person online collaboration, or for exposing LAN remote control on an untrusted public network. See What SLATE is.

#What do those little markers on the task list mean?

Every session gets a marker for where it stands: needs action (the last run was stopped or there's a next step), error, in progress (with a breathing animation, only while this session is really generating), finished but unread (cleared the moment you open it). The marker records how the last run ended; if the session was continued from the phone's remote control, the old marker is voided automatically. See Interface overview: the three-column workspace.

#A Chat is very long — will it exceed the model window?

It won't overflow straight away. When the context budget is used up, old messages are compressed into one Summary automatically, and both the compression threshold and the usage bar's denominator are calculated from the budget you set for this model. To compress once by hand, click "Compress" in the Chat. The budget is adjusted under "Settings → Context and Projects" and in "max context" on the model row, and a local endpoint's real window can be probed in one click. See Settings and security approvals.

#How do I use the ink draft Grind Mode produces?

An ink draft has three buttons: send it to Target Mode to execute, put it on the Whiteboard to reason it out, or save it as a template for reuse. Want to look before deciding — put it on the Whiteboard; want to start right away — send it to Target Mode. See Grind Mode.

#Can long-term memory get things wrong?

It can, which is why it can be edited and deleted. In the memory panel, edit the content or delete entries one by one; once outdated information is corrected, later Chats recall the new content. With automatic memory distillation on, after every round of reply it quietly reads the recent Chat once, and doesn't repeat within 45 seconds. See Memory, Profile and Knowledge.

#Who created the cards on the Whiteboard?

Two sources: ones the model creates while working (tool execution is recorded as step cards with status colours), and ones you drag out yourself. Cards, connections and step cards can all be edited and cleaned up by you. See Whiteboard-style logic chains.

#A Scheduled Task didn't run when its time came

First check the task is enabled, then check whether "Scheduled and event tasks" under "Settings → AI assistance" has been turned off — tasks stop running once it's off, but trigger records are kept. The result is archived in its own session with a prefix; find that one in the session list. See Task list and Scheduled Tasks.

#I want to write a playbook for a repeated process — where do I start?

Write it as an Actions playbook; in agent mode the model sees the catalogue automatically, reads the full text when it needs it and then follows the process. A bad version doesn't vanish into thin air — it's listed together with the reason, and every overwrite or delete is kept with a one-click rollback. See Actions playbooks.

#Can I use my own Skill with SLATE directly?

Yes. Write the Skill as a SKILL.md and it's recognised; mention it with @ in Chat afterwards and it's injected into that message's Context. An Expert Pack, by contrast, is the whole set of "persona + rules + knowledge + Skills", importable and exportable. See Built-in tools and Skills and Expert Packs.

#Still stuck?

If none of the pages above solved it, file an Issue on the Project's GitHub repository with your OS version, the steps you took and the error text verbatim — that makes it much easier to pin down:

  • You can also open it from "Settings → About" with the "GitHub" button.
